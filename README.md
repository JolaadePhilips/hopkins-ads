# Claude Hopkins — the ads, 1891–1932

A catalogue of Claude C. Hopkins' advertising, built from open archives: the actual newspaper and magazine page scans where one survives, verbatim copy where it could be recovered, and a source link on every entry.

All advertisements reproduced here were published in the United States before 1929 and are in the public domain.

**View the site:** enable GitHub Pages (Settings → Pages → Deploy from branch → main, root) and it will be live at `https://<username>.github.io/hopkins-ads/`

## What's in it

- 64 catalogued entries across 18 brands, each graded by evidence: **Verbatim ad** (transcribed from a dated period scan), **Memoir only** (Hopkins' 1927 account, no artefact found), or **Disputed**
- Scans of the actual pages, in `images/`
- 13 corrections to widely-repeated claims (the "washed with live steam" line never ran; Ovaltine was never his; the wells were 1,400 feet, not 4,000…)
- A checked list of sources and archives

Built from bulk OCR sweeps of ~7,000 issues of Printers' Ink, Saturday Evening Post, Collier's, Life, Harper's Weekly and Ladies' Home Journal on the Internet Archive, plus the open Chronicling America state mirrors and the Portal to Texas History.
